A

CSS + одна строка JS — рекомендую

Настоящая кнопка поверх плафона, понятная клавиатуре и скринридеру. JS только меняет класс и aria-pressed; вся визуальная магия остаётся в CSS.

B

Полностью CSS через checkbox

Без JavaScript, но скрытый checkbox и :has() делают разметку менее очевидной и хуже объясняют семантику кнопки.

C

JS управляет отдельным световым слоем

Больше контроля над анимацией, но для такой пасхалки это лишняя сложность и дополнительные стили состояния.
