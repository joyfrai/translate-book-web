# Пасхалка «16 переключений»

## Цель

После каждого 16-го принятого ручного переключения лампы запускать короткую эффектную сцену на десктопе, используя существующие фон, герб, обложки и типографику. Бэкенд, сетевые запросы, зависимости и постоянное хранилище не затрагиваются.

## Триггер и счётчик

- Считаются только ручные клики, которые действительно запускают переключение лампы.
- Клики во время текущей анимации игнорируются и не увеличивают счётчик.
- Автоматическое выключение через 1,2 секунды после `window.load` не учитывается.
- Эффект запускается при `manualToggleCount % 16 === 0`, поэтому повторяется на 16-м, 32-м, 48-м и каждом следующем кратном 16 клике без перезагрузки.
- Счётчик хранится только в замыкании текущей страницы и сбрасывается при навигации или обновлении.

## Сцена

- На `.library-app` добавляется класс `.lamp-easter-egg-active`; он остаётся до нажатия заметного крестика на цитатной карточке.
- Существующий фон слегка приближается и затем возвращается без проявления краёв.
- Герб получает короткое тёплое свечение.
- Обложки каталога последовательно приподнимаются небольшой волной; на странице загрузки этот этап естественно отсутствует.
- По центру основной области появляется цитатная карточка: «Многие упорны в отношении однажды избранного пути, немногие — в отношении цели». Под цитатой указан автор — Фридрих Ницше.
- Карточка получает отдельную тёмную фактурную подложку, тонкую латунную рамку и тень, чтобы не сливаться с каталогом.
- Карточка закрывается только собственной кнопкой-крестиком; клики по остальной странице её не скрывают.

## Доступность и ограничения

- Эффект работает только на десктопе вместе с интерактивной лампой.
- Сообщение имеет `role="status"` и `aria-live="polite"`.
- При `prefers-reduced-motion: reduce` остаются статичное сообщение и спокойное свечение без мерцания, зума и волны обложек.
- Карточка перехватывает клики внутри своих границ, а её крестик имеет доступное название «Закрыть цитату».
- Новые изображения, компоненты, библиотеки и серверное состояние не добавляются.

## Проверка

- Разметка обеих страниц содержит одно сообщение с согласованным текстом и доступными атрибутами.
- Скрипт считает только принятые ручные клики и использует кратность 16.
- Автоматическое выключение не вызывает увеличение счётчика.
- CSS содержит состояние сцены, анимации фона, герба, сообщения и волны обложек, плюс reduced-motion fallback.
- В браузере выполнить 16 реальных принятых кликов, проверить появление сцены, устойчивость к клику вне карточки и закрытие по крестику; затем повторить проверку на 32-м клике.
- Полный набор тестов должен пройти без изменения backend-поведения.
