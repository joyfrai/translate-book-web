# Translate Book: перенос утверждённого дизайна

## Цель

Перенести утверждённый тёмный библиотечный интерфейс на актуальный Python-webapp, не меняя очередь перевода, безопасность загрузки, хранилище, языковые настройки или download-контракты.

## Основа

- Страница `/` остаётся формой загрузки PDF, DOCX и EPUB до 30 MB.
- Селекты `source_language` и `target_language` остаются рабочими и отправляют существующие значения формы.
- Блок задач отображает реальный статус и прогресс из SQLite.
- Страница `/library` показывает только завершённые книги.
- Для каждой завершённой книги остаются реальные ссылки на оригинал и перевод.

## Визуальная система

- Тёмная зелёно-чёрная палитра, латунные акценты и бордовая главная кнопка.
- Локальный Cormorant Garamond для заголовков и названий книг.
- Логотип-герб, библиотечный интерьер и лампа из утверждённого прототипа.
- Двадцать материальных тем обложек. Тема детерминированно выбирается по ID задачи, поэтому карточка не меняет цвет при обновлении страницы.
- Обложка получает интегрированный корешок, внутреннее освещение и мягкую падающую тень без отдельной смещённой подложки.
- Кнопки скачивания всегда располагаются вертикально.

## Адаптивность

- Desktop: фиксированная левая навигация и трёхколоночный каталог.
- Tablet: горизонтальная шапка и две колонки.
- Mobile: компактная типографичная шапка с сегментированной навигацией; карточки книг состоят из мини-обложки и информации справа.
- Все поля формы, селекты и кнопки сохраняют доступные подписи и клавиатурный фокус.

## Ограничения

- Не менять обработчики upload/download, правила VirusTotal, SQLite-схему, worker и переводчик.
- Единственное изменение HTTP-слоя — безопасная выдача локальных статических дизайн-ассетов из каталога `webapp/static`.
- Не добавлять внешние CDN или сетевые зависимости.

## Проверка

- Все исходные 245 тестов должны проходить.
- Новые тесты фиксируют языковые селекты, download-ссылки, 20 тем обложек, статические ассеты и ключевые адаптивные стили.
- Обе страницы проверяются в браузере на desktop и mobile; финальный `design-qa.md` должен содержать `final result: passed`.
