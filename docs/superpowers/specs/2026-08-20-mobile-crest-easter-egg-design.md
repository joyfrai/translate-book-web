# Мобильная пасхалка «Книги проснулись»

## Цель

Добавить мобильную пасхалку в существующий библиотечный интерфейс без изменений бэкенда, новых зависимостей и дополнительных изображений. Эффект должен продолжать визуальный язык десктопной лампы, но использовать естественный для телефона жест — серию тапов по гербу.

## Область действия

- Пасхалка доступна только при ширине экрана до 640 px.
- Она работает на страницах загрузки и библиотеки, поскольку обе используют общую шапку.
- Десктопная пасхалка с лампой и её счётчик остаются без изменений.
- Состояние хранится только в памяти открытой страницы и сбрасывается при обновлении или переходе.

## Триггер

- Интерактивной зоной служит герб в мобильной шапке.
- Для запуска нужны 7 тапов за 3 секунды.
- Первый тап открывает временное окно счёта на 3 секунды. Если седьмой тап не произошёл вовремя, счётчик обнуляется.
- После успешного запуска счётчик и таймер обнуляются, поэтому сцену можно повторить ещё через 7 быстрых тапов без перезагрузки.
- Тапы по тексту «Translate Book» сохраняют обычный переход на страницу загрузки. Интерактивная зона герба не вызывает навигацию.

## Сцена

- На корневой `.library-app` добавляется отдельный мобильный класс активной сцены.
- Герб кратко получает тёплое золотое свечение.
- Видимые обложки каталога последовательно приподнимаются примерно на 6 px и возвращаются без сдвига сетки.
- На странице загрузки волна обложек отсутствует естественным образом; герб и карточка продолжают работать.
- Снизу появляется адаптированная версия существующей фактурной цитатной карточки с тем же текстом Фридриха Ницше.
- Карточка остаётся открытой после завершения анимаций и закрывается только собственной кнопкой с доступным названием «Закрыть цитату».
- Новый текст, изображения и отдельный модальный компонент не добавляются: используется существующая разметка цитаты и текущие текстуры.

## Взаимодействие и доступность

- Зона герба должна иметь семантику кнопки и доступное название, но не менять внешний вид шапки.
- Минимальная зона касания — 44 × 44 px.
- После запуска фокус переводится на крестик цитатной карточки.
- Клики вне карточки её не закрывают.
- При `prefers-reduced-motion: reduce` отключаются подъём обложек и пульсация; карточка появляется без пространственного движения.
- Пасхалка не блокирует поиск, загрузку, выбор языков и скачивание файлов после закрытия карточки.

## Технический подход

- Общая разметка шапки получает отдельный мобильный элемент управления вокруг существующего изображения герба; текстовый бренд остаётся ссылкой.
- Небольшой обработчик JavaScript хранит число тапов и идентификатор трёхсекундного таймера в замыкании страницы.
- CSS внутри существующих мобильных медиавыражений показывает зону герба, адаптирует цитатную карточку под нижнюю часть экрана и запускает короткие анимации существующих элементов.
- Сетевые запросы, хранилище задач, перевод, загрузка и скачивание не изменяются.

## Проверка

- На ширине 390 px седьмой тап в пределах 3 секунд открывает цитату; шестой тап не открывает её.
- Семь медленных тапов с превышением трёхсекундного окна не запускают сцену.
- После закрытия следующие 7 быстрых тапов повторно запускают пасхалку без обновления страницы.
- Тап по тексту бренда продолжает вести на `/`, а зона герба не меняет URL.
- Цитата закрывается только крестиком.
- На ширине более 640 px мобильная зона и мобильный обработчик не активны; десктопная лампа работает как раньше.
- В режиме reduced motion карточка доступна, а пространственные анимации отсутствуют.
- Полный набор автоматических тестов проходит без изменения backend-поведения.
