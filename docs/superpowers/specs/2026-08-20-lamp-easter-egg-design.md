# Пасхалка со светильником

## Цель

Добавить ненавязчивое десктопное взаимодействие с лампой в фоновой иллюстрации боковой панели, не затрагивая серверную логику, зависимости и мобильную шапку. Одновременно закрепить атмосферный фон основной области с глобусом при прокрутке без возврата к `background-attachment: fixed`.

## Поведение лампы

- После полной загрузки страницы лампа остаётся включённой 1,2 секунды, затем автоматически дважды мерцает и остаётся выключенной.
- Поверх плафона и небольшого пространства вокруг него располагается невидимая интерактивная зона.
- При выключении лампа дважды коротко мерцает и остаётся погашенной.
- При повторном включении лампа дважды мерцает и остаётся включённой.
- Состояние хранится только в DOM текущей страницы. Переход на другой URL или обновление страницы повторно запускает задержку 1,2 секунды, вступительное мерцание и выключение.
- Повторный клик во время анимации игнорируется, чтобы последовательность не ломалась.
- На ширине до 980 px зона взаимодействия отсутствует вместе с десктопной фоновой лампой.

## Реализация

### Разметка

В `site_header()` добавляется один элемент `button` внутри `.app-navigation`. У него нет видимого текста или оформления, но есть:

- класс `.lamp-toggle`;
- `type="button"`;
- `aria-label`, описывающий следующее действие;
- `aria-pressed`, отражающий текущее состояние.

Это не отдельный UI-компонент, а доступная зона взаимодействия поверх существующего изображения.

### Стили

- `.lamp-toggle` позиционируется абсолютными процентными координатами относительно боковой панели и покрывает плафон с небольшим запасом.
- В обычном состоянии кнопка полностью прозрачна; при клавиатурном фокусе появляется тонкая золотая обводка.
- Состояния `.lamp-is-on`, `.lamp-is-off` и `.lamp-is-flickering` управляют локальным затемняющим слоем боковой иллюстрации.
- Выключенное состояние приглушает нижнюю часть иллюстрации и убирает тёплое свечение лампы, сохраняя читаемость логотипа и навигации.
- Мерцание выполняется CSS keyframes длительностью около 450–550 мс с двумя короткими провалами яркости.
- При `prefers-reduced-motion: reduce` keyframes отключаются и используется короткое плавное изменение яркости.

### Минимальный JavaScript

Один общий helper возвращает одинаковый скрипт инициализации для обеих страниц:

1. Находит `.lamp-toggle` и `.app-navigation`.
2. После события `window.load` ждёт 1200 мс и автоматически запускает существующую последовательность выключения; по клику тот же механизм переключает лампу в обратное состояние.
3. Обновляет `aria-pressed` и `aria-label`.
4. При `prefers-reduced-motion: reduce` сразу устанавливает итоговый класс, не ожидая события анимации.
5. Не использует хранилища, таймеры фоновых задач, сетевые запросы или серверное состояние.

## Фиксированный фон основной области

- Иллюстрация `library-interior-wide.webp` переносится с прокручиваемого контейнера на отдельный `position: fixed` псевдослой основной области.
- Псевдослой начинается после фиксированной панели (`left: 230px`), не перехватывает события и остаётся под контентом.
- Затемняющий оверлей сохраняется на этом же слое, поэтому глобус и книжные полки не конкурируют с текстом.
- Иллюстрация масштабируется через `cover` на всю основную область справа от панели, поэтому на широких и высоких экранах не проявляется прямоугольная граница изображения.
- На ширине до 980 px слой становится `position: absolute`, чтобы мобильная прокрутка оставалась естественной.
- `background-attachment: fixed` не используется.

## Доступность

- Переключатель доступен с клавиатуры и имеет видимый `focus-visible`.
- Состояние и следующее действие передаются через `aria-pressed` и `aria-label`.
- Для пользователей с уменьшенным движением мерцание заменяется спокойным переходом.
- Интерактивная зона не перекрывает ссылки навигации.

## Проверка

- Тест разметки: на обеих страницах присутствует один доступный переключатель лампы.
- Тест стилей: переключатель скрыт на мобильном breakpoint, фон основной области использует отдельный фиксированный слой, `background-attachment: fixed` отсутствует.
- Браузерная проверка: загрузка даёт `включено → пауза 1,2 секунды → мерцание → выключено`, затем два клика последовательно дают `мерцание → включено → мерцание → выключено`.
- Проверка прокрутки: фон с глобусом и боковая панель сохраняют положение при прокрутке каталога.
- Проверка мобильной ширины: переключателя нет в интерактивном дереве, горизонтального переполнения нет.
- Полный существующий набор автотестов должен пройти без изменения backend-поведения.
