# Translate Book Web

Небольшая web-обёртка над `translate-book`.

- принимает `PDF`, `DOCX`, `EPUB` до 20 MB;
- кладёт задачу в SQLite и обрабатывает её отдельным worker-потоком;
- держит только одну книгу в очереди обработки;
- переводит через `codex` с выбранного исходного языка на выбранный язык результата, по умолчанию `English → Русский`;
- в форме доступны `ru`, `en`, `zh`, `ja`, `ko`, `fr`, `de`, `es`; эти коды поддерживает upstream, а в этом форке добавлен профиль `ru`;
- показывает progress по готовым чанкам при загрузке или обновлении страницы;
- после завершения отдаёт ZIP со всеми доступными результатами upstream.

Статус обновляется при загрузке страницы или ручном нажатии «Обновить». Данные хранятся в `data/` и не удаляются автоматически.
