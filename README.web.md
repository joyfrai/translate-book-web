# Translate Book Web

Небольшая web-обёртка над `translate-book`.

- принимает `PDF`, `DOCX`, `EPUB` до 30 MB;
- кладёт задачу в SQLite и обрабатывает её отдельным worker-потоком;
- держит только одну книгу в очереди обработки;
- переводит через `codex` с выбранного исходного языка на выбранный язык результата, по умолчанию `English → Русский`;
- в форме доступны `ru`, `en`, `zh`, `ja`, `ko`, `fr`, `de`, `es`; эти коды поддерживает upstream, а в этом форке добавлен профиль `ru`;
- показывает progress по готовым чанкам при загрузке или обновлении страницы;
- в публичной форме показывает путь `Файл → Языки → Результат` и подтверждает выбранное имя/размер файла до отправки;
- после завершения отдаёт ZIP со всеми доступными результатами upstream и сохраняет исходный файл рядом с job;
- перед постановкой в очередь проверяет файл локальными ограничениями формата/архива и VirusTotal; без `VIRUSTOTAL_API_KEY` или общего `JOY_VT_API_KEY` загрузка закрыта (fail-closed);
- публикует готовые переводы на отдельной странице `/library`.

Статус обновляется при загрузке страницы или ручном нажатии «Обновить». Данные хранятся в `data/` и не удаляются автоматически.

## Защита загрузки

Все загрузки проходят два последовательных слоя:

1. локальная проверка расширения, magic bytes, корректности ZIP, zip-slip путей, числа файлов, распакованного размера и коэффициента сжатия;
2. VirusTotal API v3: файл отправляется на `/api/v3/files`, затем приложение ждёт завершения анализа и отклоняет любой verdict с `malicious` или `suspicious`.

Максимум 30 MB остаётся ниже стандартного лимита VirusTotal для прямого upload endpoint. На runtime сервис получает общий `JOY_VT_API_KEY` из `/root/joy-core/security/secrets/.env.virustotal`; значение не копируется в проектный `.env`. Upload уже публичный, поэтому для production нужен отдельный rate limit и abuse protection. Публичная библиотека доступна на `/library`: в каждой карточке есть ссылки на `/download/<job_id>/original` с исходным языком и `/download/<job_id>/translated` с языком перевода. Старый `/download/<job_id>` оставлен как ссылка на перевод.
